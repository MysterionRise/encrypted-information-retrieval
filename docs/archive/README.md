# Archive

**Nothing in this folder is a current claim about the code.**

These documents are kept for history. They were written between January and November 2025 as
planning and target-state material, and they contain statements the code does not support:
- compliance checkmarks,
- test counts and coverage figures,
- latency estimates,
- controls such as FIPS HSMs, CloudTrail integration, PIR and TEEs.

They were moved here in October 2026 under issue #33. Current documentation:
- [`../README.md`](../README.md) for the documentation map.
- [`../THREAT_MODEL.md`](../THREAT_MODEL.md) for what the code protects and leaks.
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md), "As built" section.
- [`../ROADMAP.md`](../ROADMAP.md) for planned work.

| File | What it was |
| --- | --- |
| `ANALYSIS.md` | Background analysis of encrypted information retrieval for financial services (November 2025). |
| `GAP_ANALYSIS.md` | 2025 gap analysis with scores, test counts and timelines that are now stale. |
| `GITHUB_ISSUES.md` | Markdown backlog that was never created as GitHub issues. It was replaced by the issue tracker and `ROADMAP.md`. |
| `MVP_COMPLETION_SUMMARY.md` | "Phase 0" milestone summary from November 2025. |
| `LLM_SYSTEM_ANALYSIS.md` | Long-form system description generated as LLM context in November 2025. |
| `COMPLIANCE_NOTES.md` | DORA, PCI DSS, NYDFS and GDPR control mapping, with checkmarks for controls that were never implemented. |
| `OPE_TO_ORE.md` | OPE-to-ORE migration guide. It overstates the ORE prototype; see `../THREAT_MODEL.md`. |

Relative links inside these files may be broken, because the files moved.
